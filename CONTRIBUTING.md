# Contributing to SuperCSV

SuperCSV is not accepting contributions or issues at this time. The specification and reference implementation are under active development with a planned roadmap.

Security reports via [security advisories](https://github.com/supercsv/supercsv/security/advisories/new) are welcome.

This policy will be revisited as the project matures.
