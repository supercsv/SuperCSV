# Code of Conduct

SuperCSV is a read‑only public repository.  
We do not accept issues, pull requests, discussions, or community contributions at this time.

Although there is no interactive community space, we expect anyone who engages with the project — including through forks, references, or external discussion — to do so respectfully and professionally.

If you encounter behaviour related to this project that raises serious concerns, you may report it privately via GitHub's security advisory workflow:

https://github.com/supercsv/supercsv/security/advisories/new

This Code of Conduct will be expanded if and when community interaction is enabled in the future.
